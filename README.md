# Kalendar-PWII

KALENDAR es una plataforma web enfocada en centralizar la información de eventos relacionados con el K-pop.

La plataforma permitirá que los usuarios fans consulten y guarden eventos de su interés. También permitirá que los organizadores, como cafeterías, tiendas o comunidades, publiquen y administren sus eventos.

## Descripción de las carpetas

### KALENDAR

Contiene los proyectos correspondientes al frontend y al backend de la aplicación.

### backend

Contiene el proyecto `Kalendar.Api`, desarrollado con ASP.NET Core Web API. En esta parte se desarrollará la lógica de la aplicación y la comunicación con la base de datos.

### frontend

Contiene el proyecto `kalendar-web`, desarrollado con Angular. En esta parte se encuentran los componentes y las ventanas de la aplicación.
